## Пункт 2. Переобучение сети по рецепту Lloyd (число нейронов по формуле, длинное обучение)

**Параметры:**
* Размер выборки $N = 30\,000$ (равномерно по $D$), разбиение 90% train / 10% val; независимый тест — $100\,000$ равномерных точек.
* Число нейронов по формуле (30) статьи Lloyd et al. ($K_1 = 4.33$, $K_2 = 16$, $n = 6$): $k = \lfloor (\log_{10} N)^{-K_1} \cdot K_2 \cdot N/(n+2) \rfloor =$ **91**, число параметров: **729**.
* Вход масштабируется в $[-1, 1]$, целевая переменная — в $[0, 1]$.
* Архитектура: `Input(6) -> 91 (sigmoid) -> 1 (linear)`.
* Обучение: полный батч, метод L-BFGS (`scipy`), до 5000 итераций (остановка на **3022** итерации, время **672 с**). Adam, как в предыдущей сети, не использовался.

**Результаты:**

| Показатель | Значение |
| :--- | :---: |
| Loss train / val (нормированный масштаб) | `5.030e-04` / `7.361e-04` |
| Интеграл сети по $D$ / точный $I(D)$ | `0.9882` (ошибка **1.18%**, ориентир $\le 5\%$) |
| $R^2$ на тесте, вся область | `0.5168` |
| $R^2$ на тесте, только пик ($g > 0.01 \cdot \max(g)$, 7032 точки) | `0.4729` |
| Минимальное значение сети на тесте | `-0.0593` |

**Выводы:**
* Интеграл сети по всей области $D$ отличается от точного $I(D)$ на 1.18%, то есть укладывается в ориентир 5%.
* Качество в пике остаётся низким: $R^2 = 0.47$, то есть пик выучен лишь частично (у предыдущей сети с 20 нейронами локальный $R^2$ в пике был около 0; тестовые выборки разные, поэтому сравнение приблизительное).
* Сеть по-прежнему принимает отрицательные значения (минимум $-0.059$), поэтому отрицательные вероятности возможны.
* К концу обучения loss ещё убывал (на 3022 итерации выхода на плато не было).
* Вероятно, улучшение качества в пике связано со следующим пунктом (гибридная выборка точек); это предстоит проверить.
